# Markdown 写作指南

Markdown 是一种轻量级标记语言，让你专注于写作本身。

## 标题

使用 `#` 表示标题层级：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 列表

无序列表：
- 第一项
- 第二项
- 第三项

有序列表：
1. 第一步
2. 第二步
3. 第三步

## 自定义容器

::: info
This is an info box.
:::

::: tip Tip
This is a tip.
:::

::: danger
This is a dangerous warning.
:::

::: details 点击展开
This is a details block.
:::

::: warning This is a warning.
- 列表项
- 另一项
:::

::: danger STOP
这是一个危险警告。
:::
