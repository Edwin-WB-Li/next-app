# 欢迎使用博客系统

这是一个基于 **Next.js 16** 构建的简洁博客系统。它支持：

- 📝 Markdown 文章编辑与预览
- 🚀 文章发布与下架管理
- ⚡ 服务端渲染，加载迅速

## 快速开始

访问后台管理页面 `/admin`，即可在线编辑、发布文章。

## 技术栈

| 技术 | 说明 |
|------|------|
| Next.js 16 | React 全栈框架 |
| React 19 | UI 库 |
| Tailwind CSS | 原子化样式 |
| react-markdown | Markdown 渲染 |

祝你使用愉快！
