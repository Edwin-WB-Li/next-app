# 四姑娘山大峰攀登手记

## 路线攻略

四姑娘山大峰海拔 5025 米，是入门级雪山攀登的首选。从日隆镇出发，经海子沟到大本营，次日凌晨冲顶。

**详细行程：**
- **Day 1**：成都 → 日隆镇（约 4 小时车程），适应海拔
- **Day 2**：日隆镇 → 大本营（约 15km，徒步 6-7 小时）
- **Day 3**：大本营 → 冲顶 → 返回日隆镇（凌晨 2 点出发，冲顶后下撤）

## 路况难点

1. **高反**：海拔 4000 米以上高反明显，提前服用红景天
2. **碎石坡**：冲顶路段碎石较多，需集中注意力
3. **天气多变**：山区天气瞬息万变，保暖防风是关键

## 装备清单

| 类别 | 物品 |
|------|------|
| 头部 | 保暖帽、头灯、雪镜 |
| 上身 | 速干内衣、抓绒衣、冲锋衣、羽绒服 |
| 下身 | 速干裤、软壳裤、冲锋裤 |
| 脚部 | 高帮登山鞋、厚羊毛袜、雪套 |
| 其他 | 登山杖、保温杯、手套、防晒霜 |

## 食宿补给

- **日隆镇**：住宿条件一般，但价格实惠，可补充物资
- **大本营**：通铺帐篷，提供简单餐食，条件艰苦

## 避坑小贴士

1. 一定要选择正规户外俱乐部，不要独自攀登
2. 冲顶当天无论多热都要带羽绒服，山顶极冷
3. 保温杯必备，普通水壶会结冰
4. 提前一周开始服用抗高反药物

## 个人感悟

站在大峰顶端的那一刻，5000 米的海拔让我呼吸困难，但眼前的云海和日出让一切都值了。这是我人生的第一座五千米雪山，也是户外生涯中最重要的里程碑。山在那里，你只需一步一步走过去。
